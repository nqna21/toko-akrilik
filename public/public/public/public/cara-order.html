Cara order

  1. Pilih produkBuka katalog atau galeri karya, lalu pilih produk yang kamu mau.
  2. Atur ukuran, tebal, bentuk, dan finishingHarga dihitung langsung. Untuk bentuk mengikuti kontur desain, biaya potong berupa perkiraan dan dikonfirmasi saat file diverifikasi.
  3. Unggah desainUnggah file di halaman produk. Kalau file terlalu besar, pilih "kirim lewat WhatsApp" dan sebutkan kode pesanan.
  4. CheckoutIsi nama dan nomor WhatsApp, pilih ambil sendiri atau kirim. Kamu mendapat kode pesanan.
  5. Bayar dan unggah buktiTransfer sesuai total, lalu unggah bukti di halaman Lacak pesanan.
  6. Pantau statusStatus berjalan dari antre produksi, cetak UV, potong, pemeriksaan akhir, sampai siap diambil atau dikirim.

Panduan menyiapkan desain

Panduan umum agar hasil cetak sesuai harapan. Kalau ragu, kirim file apa adanya dan kami bantu cek.

  • Format yang diterima: PNG, JPG, WEBP, PDF, SVG, AI, EPS, CDR, DXF, dan ZIP.
  • Logo dan teks: lebih baik berupa vektor (PDF, SVG, AI, EPS, CDR) supaya tepinya tajam di ukuran berapa pun.
  • Foto dan gambar: gunakan resolusi setinggi mungkin. Gambar kecil yang diperbesar akan terlihat pecah.
  • Garis potong: untuk bentuk mengikuti kontur, sertakan garis potong sebagai garis terpisah (tanpa isi warna) di file yang sama atau file DXF/SVG tersendiri.
  • Tepi desain: beri jarak aman dari garis potong agar teks atau gambar penting tidak terpotong.
  • Warna: warna di layar dan hasil cetak UV bisa sedikit berbeda, apalagi di akrilik bening. Pilih finishing dengan lapisan putih kalau warna harus pekat.
